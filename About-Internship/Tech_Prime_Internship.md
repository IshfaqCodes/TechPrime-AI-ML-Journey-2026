- **Topics:** Variables, data types, loops, functions, OOP, file handling

- **Deliverables:** Lectures, Exercises, GitHub Upload, README

### Week 4 — Regression
- **Topics:** Linear & Polynomial Regression, metrics

- **Topics:** Logistic Regression, KNN, Decision Trees, Random Forest, SVM

### Week 6 — Unsupervised Learning

- **Deliverables:** Lectures, Exercises, GitHub Upload, README

### Week 7 — ML Pipeline
- **Topics:** Feature engineering, cross-validation, hyperparameter tuning

### Week 8 — Deep Learning & NLP (Capstone)
